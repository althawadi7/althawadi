# شجرة العائلة (نسخة عمل مرتبة)

> هذا الملف للعمل السريع بيننا: أنت ترسل الأسماء، وأنا أرتبها مباشرة.

## العرض البصري (الهيكل العام)

```text
بني خالد
└─ العماير
   └─ حسن
      └─ هلال
         └─ خليفة
            ├─ علي
            │  ├─ محمد
            │  └─ علي
            └─ عيسى
               ├─ محمد
               ├─ هلال
               ├─ راشد
               │  ├─ جاسم → غانم → عبدالله → نايف → عبدالعزيز
               │  ├─ هلال → ابراهيم → (٩ أبناء)
               │  ├─ حسن
               │  ├─ أحمد → ابراهيم → (٥ أبناء)
               │  └─ خليفه
               └─ عبدالله
                  ├─ محمد (١) → عبدالله، عيسى، أحمد، علي
                  ├─ أحمد → يوسف → أحمد → (٥ أبناء)
                  ├─ محمد (٢) → سعيد، عيسى، أحمد، سلطان
                  └─ هلال  ◄── (تفصيله بالأسفل)
```

├─ أحمد

├─ عبدالله
│  ├─ هلال
│  ├─ أحمد
│  ├─ محمد
│  ├─ فهد
│  └─ عيسى
├─ جمال
│  ├─ خالد

## تفصيل الفروع (أسهل للتعديل)

### 1) خط النسب
- بني خالد
  - العماير
    - حسن
      - هلال
        - خليفة

### 2) أبناء خليفة
- علي
- عيسى

### 3) أبناء علي
- محمد
- علي

### 4) أبناء عيسى
- محمد
- هلال
- راشد
- عبدالله

### 5) أبناء راشد _(من المخطط المرسل)_
- جاسم
  - غانم
    - عبدالله
      - نايف
        - عبدالعزيز
- هلال
  - ابراهيم
    - عبدالعزيز، عبدالله، عبدالرحمن، فيصل، سليمان
    - هلال، طارق، محمد، وائل
- حسن
- أحمد
  - ابراهيم
    - يوسف، عارف، محمد، عبدالله، راشد
- خليفه

### 6) أبناء عبدالله (أخو راشد) _(من المخطط + الأجداد)_
- محمد (١)
  - عبدالله
  - عيسى
  - أحمد
  - علي
- أحمد
  - يوسف
    - أحمد
      - راشد، فهد، عبدالناصر، جاسم، عبدالعزيز
- محمد (٢)
  - سعيد، عيسى، أحمد، سلطان
- هلال

### 7) هلال بن عبدالله بن عيسى — وأحفاده

**أبناء هلال:** حسن، عبدالعزيز، أحمد، عبدالله، جمال، عبدالحكيم، عيسى

| الابن | الأبناء |
|--------|---------|
| **حسن** | ابراهيم، أحمد |
| ↳ ابراهيم | حسن، خالد |
| **عبدالعزيز** | — |
| **أحمد** | سلطان |
| **عبدالله** | هلال، أحمد، محمد، فهد، عيسى |
| **جمال** | خالد، طلال |
| **عبدالحكيم** | عبدالله |
| **عيسى** | عبدالله |

**قائمة نصية (للنسخ السريع):**

- **حسن**
  - ابراهيم
    - حسن
    - خالد
  - أحمد
- **عبدالعزيز** _(لا أبناء مذكورون بعد)_
- **أحمد**
  - سلطان
- **عبدالله**
  - هلال
  - أحمد
  - محمد
  - فهد
  - عيسى
- **جمال**
  - خالد
  - طلال
- **عبدالحكيم**
  - عبدالله
- **عيسى**
  - عبدالله

## طريقة الإدخال المتفق عليها
- `علي - عيسى` => **إخوة** (نفس الأب).
- `عيسى عنده: محمد - هلال` => أبناء عيسى.
- `حسن: ابراهيم، أحمد` => أبناء حسن.
