# شجرة العائلة (نسخة عمل مرتبة)

> هذا الملف للعمل السريع بيننا: أنت ترسل الأسماء، وأنا أرتبها مباشرة.

## قاعدة المخطط
- **سهم ↓** = ابن (أب → ابن).
- **أسماء بلا سهم** (أفقي أو قائمة) = **إخوة** (نفس الأب).

## العرض البصري (الهيكل العام)

```text
بني خالد → العماير → حسن → هلال → خليفة
├─ علي → محمد → علي
└─ عيسى
   ├─ محمد · هلال
   ├─ راشد
   │  └─ جاسم
   │     ├─ غانم → عبدالله → نايف → عبدالعزيز
   │     ├─ خليفه
   │     ├─ أحمد → ابراهيم → عيسى → (خليفه، راشد، ناصر، خالد | يوسف → …)
   │     ├─ حسن → (علي، راشد، عبدالله، محمد — فروع)
   │     └─ هلال → ابراهيم → (٩ إخوة + عيسى → ٥ أبناء)
   ├─ هلال · حسن · أحمد · خليفه  (أبناء راشد مباشرة)
   └─ عبدالله
      ├─ محمد (١) → عبدالله، عيسى، أحمد، علي
      ├─ أحمد → يوسف → (أحمد، عبدالناصر، محمد، خالد) + فروعهم
      ├─ محمد (٢) → محمد→عبدالله، سعيد، عيسى، يوسف→أحمد، …
      └─ هلال  (تفصيل §7)
```

---

## تفصيل فرع: هلال بن عبدالله بن عيسى

```text
هلال بن عبدالله بن عيسى
├─ حسن → ابراهيم (حسن، خالد) · أحمد
├─ عبدالعزيز
├─ أحمد → سلطان
├─ عبدالله → هلال، أحمد، محمد، فهد، عيسى
├─ جمال → خالد، طلال
├─ عبدالحكيم → عبدالله
└─ عيسى → عبدالله
```

---

## 5) أبناء راشد

- **جاسم**
  - **غانم** → عبدالله → نايف → عبدالعزيز
  - **خليفه**
  - **أحمد** → ابراهيم → عيسى
    - إخوة: خليفه، راشد، ناصر، خالد
    - **راشد** → أحمد
    - **يوسف** → عارف، محمد، أحمد، عبدالله، راشد
      - عارف → فيصل → عيسى
      - محمد → فيصل → عبدالله
  - **حسن**
    - علي → محمد (حسن، راشد) · حسن
    - راشد → عيسى، حسن، محمد، عصام، عبدالرحمن
    - عبدالله → علي، حسن
    - محمد → حسن، راشد
  - **هلال** → ابراهيم
    - إخوة: فيصل، سليمان، عبدالرحمن، عبدالله، عبدالعزيز، هلال، طارق، محمد، وائل
    - **عيسى** → عبدالله، هلال، راشد، عمر، بدر
- **هلال** · **حسن** · **أحمد** · **خليفه** _(أبناء راشد مباشرة — بلا ذرية في المخطط)_

## 6) أبناء عبدالله (أخو راشد)

- **محمد (١)** → عبدالله، عيسى، أحمد، علي
- **أحمد** → يوسف
  - **أحمد** → يوسف، راشد، فهد
  - **عبدالناصر** → يوسف
  - **محمد** → جاسم، عبدالعزيز، يوسف
  - **خالد**
- **محمد (٢)**
  - محمد → عبدالله
  - إخوة: عبدالله، سعيد، عيسى
  - يوسف → أحمد
  - إخوة: محمد، سلطان، علي
- **هلال** → (§7)

---

## طريقة الإدخال
- `علي - عيسى` => إخوة.
- `عيسى: محمد - هلال` => أبناء عيسى.
- `حسن: ابراهيم، أحمد` => أبناء حسن.

## ملاحظات
- مناطق **???** في الصورة = شروحات مخفية، ليست أسماء.
- **البراء** تحت عبدالحكيم = مُستبعد حتى تأكيد.
- **غانم** (وليس عقيل) تحت جاسم.

## سطر التحديث القادم
`أبناء فلان: اسم - اسم` أو مخطط جديد.
