# شجرة العائلة (نسخة عمل مرتبة)

> هذا الملف للعمل السريع بيننا: أنت ترسل الأسماء، وأنا أرتبها مباشرة.

## قاعدة المخطط
- **سهم ↓** = ابن (أب → ابن).
- **أسماء بلا سهم** (أفقي أو قائمة) = **إخوة** (نفس الأب).

## العرض البصري (الهيكل العام)

```text
بني خالد → العماير → حسن → هلال → خليفة
├─ علي → محمد → علي
└─ عيسى
   ├─ محمد · هلال · راشد · عبدالله  (إخوة)
   ├─ راشد → جاسم · هلال · حسن · أحمد · خليفة · غانم  (إخوة)
   └─ عبدالله
      ├─ محمد (١) → …
      ├─ أحمد → يوسف → …
      ├─ محمد (٢) → …
      └─ هلال  (§7)
```

---

## 3) أبناء عيسى بن خليفة _(أربعة أبناء — إخوة)_

- **محمد**
- **هلال**
- **راشد** → (§5)
- **عبدالله** → (§6)

---

## 4) فرع علي بن خليفة _(سهم = ابن — ليس إخوة)_

- **علي** → **محمد** → **علي**

---

## 5) أبناء راشد بن عيسى _(ستة أبناء — إخوة تحت راشد مباشرة)_

> **مهم:** جاسم، هلال، حسن، أحمد، خليفة، غانم كلهم **أبناء راشد** — لا يُوضَع أحدهم تحت الآخر.

- **جاسم** _(بلا ذرية في المخطط الحالي)_
- **هلال** → ابراهيم
  - إخوة: فيصل، سليمان، عبدالرحمن، عبدالله، عبدالعزيز، هلال، طارق، محمد، وائل
  - **عيسى** → عبدالله، هلال، راشد، عمر، بدر
- **حسن**
  - **علي** → محمد (حسن، راشد) · حسن
  - **راشد** → عيسى، حسن، محمد، عصام، عبدالرحمن
  - **عبدالله** → علي، حسن
  - **محمد** → حسن، راشد
- **أحمد** → ابراهيم → عيسى
  - إخوة: خليفة، راشد، ناصر، خالد
  - **راشد** → أحمد
  - **يوسف** → عارف، محمد، أحمد، عبدالله، راشد
    - عارف → فيصل → عيسى
    - محمد → فيصل → عبدالله
- **خليفة**
- **غانم** → عبدالله → نايف → عبدالعزيز

---

## 6) أبناء عبدالله بن عيسى _(أربعة أبناء — إخوة)_

- **محمد (١)** → عبدالله، عيسى، أحمد، علي
- **أحمد** → يوسف
  - **أحمد** → يوسف، راشد، فهد
  - **عبدالناصر** → يوسف
  - **محمد** → جاسم، عبدالعزيز، يوسف
  - **خالد**
- **محمد (٢)**
  - محمد → عبدالله
  - إخوة: عبدالله، سعيد، عيسى
  - يوسف → أحمد
  - إخوة: محمد، سلطان، علي
- **هلال** → (§7)

---

## 7) أبناء هلال بن عبدالله بن عيسى _(سبعة أبناء — إخوة)_

```text
هلال بن عبدالله بن عيسى
├─ حسن → ابراهيم (حسن، خالد) · أحمد
├─ عبدالعزيز
├─ أحمد → سلطان
├─ عبدالله → هلال، أحمد، محمد، فهد، عيسى
├─ جمال → خالد، طلال
├─ عبدالحكيم → عبدالله
└─ عيسى → عبدالله
```

---

## طريقة الإدخال
- `علي - عيسى` => إخوة.
- `عيسى: محمد - هلال` => أبناء عيسى.
- `حسن: ابراهيم، أحمد` => أبناء حسن.

## ملاحظات
- مناطق **???** في الصورة = شروحات مخفية، ليست أسماء.
- **البراء** تحت عبدالحكيم = مُستبعد حتى تأكيد.
- **غانم** (وليس عقيل) **ابن راشد** مباشرة — خط نايف وعبدالعزيز تحته.

## سطر التحديث القادم
`أبناء فلان: اسم - اسم` أو مخطط جديد.
