# شجرة العائلة (نسخة عمل مرتبة)

> هذا الملف للعمل السريع بيننا: أنت ترسل الأسماء، وأنا أرتبها مباشرة.

## العرض البصري (الهيكل العام)

```text
بني خالد
└─ العماير
   └─ حسن
      └─ هلال
         └─ خليفة
            ├─ علي
            │  ├─ محمد
            │  └─ علي
            └─ عيسى
               ├─ محمد
               ├─ هلال
               ├─ راشد
               │  ├─ جاسم
               │  ├─ هلال
               │  ├─ حسن
               │  ├─ أحمد
               │  └─ خليفه
               └─ عبدالله
                  ├─ محمد
                  ├─ أحمد
                  ├─ محمد
                  └─ هلال  ◄── (تفصيله بالأسفل)
```

## تفصيل الفروع (أسهل للتعديل)

### 1) خط النسب
- بني خالد
  - العماير
    - حسن
      - هلال
        - خليفة

### 2) أبناء خليفة
- علي
- عيسى

### 3) أبناء علي
- محمد
- علي

### 4) أبناء عيسى
- محمد
- هلال
- راشد
- عبدالله

### 5) أبناء راشد
- جاسم
- هلال
- حسن
- أحمد
- خليفه

### 6) أبناء عبدالله (أخو راشد)
- محمد
- أحمد
- محمد
- هلال

### 7) هلال بن عبدالله بن عيسى — وأحفاده

**أبناء هلال:** حسن، عبدالعزيز، أحمد، عبدالله، جمال، عبدالحكيم، عيسى

| الابن | الأبناء |
|--------|---------|
| **حسن** | ابراهيم، أحمد |
| ↳ ابراهيم | حسن، خالد |
| **عبدالعزيز** | — |
| **أحمد** | سلطان |
| **عبدالله** | هلال، أحمد، محمد، فهد، عيسى |
| **جمال** | خالد، طلال |
| **عبدالحكيم** | عبدالله |
| **عيسى** | عبدالله |

**قائمة نصية (للنسخ السريع):**

- **حسن**
  - ابراهيم
    - حسن
    - خالد
  - أحمد
- **عبدالعزيز** _(لا أبناء مذكورون بعد)_
- **أحمد**
  - سلطان
- **عبدالله**
  - هلال
  - أحمد
  - محمد
  - فهد
  - عيسى
- **جمال**
  - خالد
  - طلال
- **عبدالحكيم**
  - عبدالله
- **عيسى**
  - عبدالله

## طريقة الإدخال المتفق عليها
- `علي - عيسى` => **إخوة** (نفس الأب).
- `عيسى عنده: محمد - هلال` => أبناء عيسى.
- `حسن: ابراهيم، أحمد` => أبناء حسن.
